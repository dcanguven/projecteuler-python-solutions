<h3>Daily Project Euler in Python</h3>

A collection of Project Euler solutions in Python, used for regular problem-solving practice and coding agent experiments.

The repository includes both my own solutions and solutions produced with different agent setups, including local agents, OpenAI agents and Anthropic Claude. Each solution follows the same format: problem screenshot, short summary, code, result and execution time.

All original problems are available at:
https://projecteuler.net/
